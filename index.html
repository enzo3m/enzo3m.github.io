Materiale didattico

1. Introduzione alla programmazione a oggetti

La programmazione a oggetti (OOP) organizza il software in oggetti con stato (attributi) e comportamento (metodi). La classe è lo stampo, l'oggetto è l'istanza.

  • Incapsulamento: campi private, interfaccia public.
  • Costruttore: inizializza l'oggetto creato con new.
  • Ereditarietà / Polimorfismo: riuso tramite gerarchie (cenni).

2. I diagrammi UML

Il diagramma delle classi ha riquadri nome / attributi / metodi, visibilità + - #, associazioni con molteplicità e generalizzazione per l'ereditarietà.

+-------------------+
|     Studente      |
+-------------------+
| - matricola: int  |
| - nome: String    |
+-------------------+
| + studia(): void  |
+-------------------+
        | 1..* frequenta
        v
+-------------------+
|      Corso        |
+-------------------+

3. Le classi in Java

public class Studente {
    private int matricola;
    private String nome;

    public Studente(int matricola, String nome) {
        this.matricola = matricola;
        this.nome = nome;
    }

    public String getNome() { return nome; }
    public void setNome(String nome) { this.nome = nome; }

    public void studia() {
        System.out.println(nome + " sta studiando.");
    }

    public static void main(String[] args) {
        Studente s = new Studente(101, "Mario");
        s.studia();
    }
}

Attività di laboratorio

Lab 1 — La tua prima classe Java

Obiettivo: classe Libro con titolo, autore, pagine.

  1. Crea il file Libro.java.
  2. Campi private + costruttore + getter/setter.
  3. Metodo scheda() per stampare la descrizione.
  4. Nel main crea 2 oggetti e testali.
public class Libro {
    private String titolo;
    private String autore;
    private int pagine;

    public Libro(String titolo, String autore, int pagine) {
        this.titolo = titolo; this.autore = autore; this.pagine = pagine;
    }
    public void scheda() {
        System.out.println(titolo + " di " + autore + " (" + pagine + " pp.)");
    }
}

Lab 2 — Traduzione di un diagramma UML in Java

Regole: classe UML → classe Java; - nome: Tipo → campo privato; + nome() → metodo pubblico; molteplicità * → ArrayList.

import java.util.ArrayList;
public class Corso {
    private String titolo;
    private ArrayList<Studente> iscritti = new ArrayList<>();
    public Corso(String titolo) { this.titolo = titolo; }
    public void iscrivi(Studente s) { iscritti.add(s); }
}

Esercizio: implementa Studente + Corso del diagramma sopra e verifica l'iscrizione in un main.
